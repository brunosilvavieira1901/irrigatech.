# 🌱 IrrigaTech
Sistema de irrigação inteligente para apoiar a recomposição da paisagem e o uso consciente da água.

## Estrutura
- `banco-de-dados/`: Supabase e PostgreSQL.
- `mobile/`: aplicativo React Native, TypeScript e Expo.
- `firmware/`: ESP8266 com MicroPython e sensores.
- `front-end/`: site em HTML, CSS e JavaScript.
- `ia/`: estudos e proposta de análise dos dados.

> Este pacote recupera a estrutura e a documentação já definidas. Alguns códigos originais não foram recuperados e estão identificados nos READMEs das pastas.

## Tecnologias
Supabase/PostgreSQL, ESP8266/MicroPython, ADS1115, DS18B20, React Native, Expo, HTML, CSS, JavaScript e estudos de Python/Scikit-learn.
