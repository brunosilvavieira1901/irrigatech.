# Back-end

Nesta pasta ficará o desenvolvimento do back-end do IrrigaTech.

O back-end será responsável por receber os dados enviados pelo ESP8266, processar as informações dos sensores e realizar a comunicação com o banco de dados.

Funcionalidades:
- Recebimento dos dados dos sensores.
- Comunicação com o Supabase.
- Processamento das informações de irrigação.
- Integração com o front-end e aplicativo.

Tecnologias planejadas:
- Python
- API
- Supabase
