# 🗄️ Banco de Dados — IrrigaTech

> Documentação da estrutura do banco de dados responsável pelo armazenamento das informações do sistema de irrigação inteligente IrrigaTech.

---

## 🌱 1. Sobre o banco de dados

O banco de dados do **IrrigaTech** foi desenvolvido utilizando **PostgreSQL**, por meio da plataforma **Supabase**.

Sua principal função é armazenar as informações coletadas pelos sensores do sistema de monitoramento de plantas, permitindo acompanhar as condições do solo e do ambiente em tempo real.

Os dados armazenados podem ser utilizados pelo aplicativo para apresentar informações sobre a umidade, luminosidade, temperatura e funcionamento da bomba de irrigação.

---

## ⚙️ 2. Tecnologias utilizadas

| Tecnologia | Função |
|---|---|
| PostgreSQL | Gerenciamento do banco de dados |
| Supabase | Plataforma de armazenamento e integração |
| SQL | Criação e gerenciamento das tabelas |
| Supabase Realtime | Atualização de informações em tempo real |

---

## 💻 3. Criação da tabela

A tabela `irrigacao` foi criada para armazenar os dados recebidos pelos sensores conectados ao sistema.

### Código SQL

```sql
CREATE TABLE public.irrigacao (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    sensor1 INTEGER,
    sensor2 INTEGER,
    sensor3 INTEGER,
    media INTEGER,
    luminosidade INTEGER,
    temperatura REAL,
    bomba TEXT
);
```

---

## 📊 4. Estrutura da tabela

A tabela possui nove colunas responsáveis por organizar os dados coletados pelo sistema.

| Coluna | Tipo | Descrição |
|---|---|---|
| `id` | BIGINT | Identificador único do registro |
| `created_at` | TIMESTAMPTZ | Data e horário do registro |
| `sensor1` | INTEGER | Leitura do sensor de umidade 1 |
| `sensor2` | INTEGER | Leitura do sensor de umidade 2 |
| `sensor3` | INTEGER | Leitura do sensor de umidade 3 |
| `media` | INTEGER | Média das leituras dos sensores |
| `luminosidade` | INTEGER | Valor de luminosidade do ambiente |
| `temperatura` | REAL | Temperatura registrada |
| `bomba` | TEXT | Estado da bomba de irrigação |

---

## 🔧 5. Como funciona?

O funcionamento do banco de dados acontece por meio das seguintes etapas:

1. **Coleta:** os sensores realizam a leitura da umidade do solo e das condições do ambiente.
2. **Envio:** as informações são encaminhadas ao sistema.
3. **Armazenamento:** os dados são registrados na tabela `irrigacao`, no Supabase.
4. **Consulta:** o aplicativo acessa os registros armazenados.
5. **Atualização:** o Supabase Realtime permite acompanhar novas informações sem precisar atualizar manualmente a página, quando configurado.

---

## 📱 6. Integração com o aplicativo IrrigaTech

O aplicativo IrrigaTech utiliza o Supabase para acessar os dados armazenados no banco de dados.

A integração permite:

- 🌱 Consultar as últimas leituras dos sensores.
- 💧 Acompanhar os níveis de umidade do solo.
- ☀️ Consultar a luminosidade do ambiente.
- 🌡️ Visualizar a temperatura registrada.
- 🚿 Acompanhar o estado da bomba de irrigação.
- 🔄 Receber atualizações por meio do Supabase Realtime.

---

## 🎯 7. Objetivo do banco de dados

O banco de dados foi desenvolvido para centralizar e organizar as informações do sistema IrrigaTech.

Com isso, o projeto consegue armazenar o histórico das leituras, facilitar o acompanhamento das condições das plantas e auxiliar no funcionamento de um sistema de irrigação inteligente.
